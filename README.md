# 人貓日記

自創角色「人貓」的 3D 換裝 × 生活日記遊戲。先在換衣間幫人貓換裝、擺動作，再穿著那套衣服回家：家裡有自己的房間、妹妹的房間、爸媽房間、客廳、廚房、廁所和前後陽台。跟家人說話、照著真實發生過的事完成任務，完成後那件事會寫進日記。

整個遊戲只有一個檔案 `index.html`，不需要伺服器或後端。3D 引擎 three.js 從 CDN 載入。

## 新增日記內容

打開 `index.html`，搜尋 `const DIARY`。所有人物、地點、事件和任務都寫在這一個資料區塊裡：

- `me`：主角（自己）的名字、介紹、個性、口頭禪
- `people`：家裡的人，包含台詞、外觀顏色、身形比例，以及會待的地方（`spots`）和輪流去的順序（`schedule`）
- `events`：日記的每一頁（日期、地點、有誰、發生了什麼、心情）
- `quests`：任務。`steps` 會照順序進行，`at` 填人物 id 或物品 id（`desk` 書桌、`door` 大門、`slide` 落地窗），`lines` 是對話；`repeat: true` 的任務睡一覺起來會再發生

> 網站放上 GitHub Pages 後任何人都看得到。真實姓名、學校、住址等，建議改成暱稱或模糊的說法。

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 走路 | WASD 或方向鍵（按住 Shift 跑步） | 左下角搖桿 |
| 互動、對話、下一句 | E、空白鍵或 Enter | 右下角「互動」按鈕 |
| 選對話選項 | 數字鍵 1–4 | 點選項 |
| 打開日記 | J | 「日記」按鈕 |
| 今天要做的事 | Q | 「今天」按鈕 |
| 轉動鏡頭 | 在畫面上拖曳，滾輪縮放 | 在畫面上拖曳 |

家裡可以做的事：電腦玩「接冰淇淋」小遊戲、床上睡覺／滑手機／看影片、衣櫃換衣服或照鏡子、床頭櫃上的日記本、冰箱拿冰淇淋、開關客廳的電視和落地窗、從大門出去巷口買麵線。睡覺可以切換白天和晚上，睡醒就是新的一天。

換衣間的「下載 PNG 圖檔」會把目前的穿搭和動作存成透明背景的 PNG（1600 像素的畫面裁成剛好包住人貓）。

遊戲進度、穿搭和動作會存在瀏覽器裡（localStorage），下次打開會接著玩。

## 用 GitHub Pages 免費上架

1. 到 GitHub 建立一個新的 repository，例如 `rencat`，設為 Public。
2. 在 repository 頁面按 **Add file → Upload files**，把 `index.html`（和這份 README）拖進去，按 **Commit changes**。
3. 到 **Settings → Pages**，在 **Build and deployment** 的 Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 等大約一分鐘，同一頁上方會出現網址，格式是 `https://你的帳號.github.io/rencat/`。

之後要更新，只要再上傳新的 `index.html` 覆蓋舊的，網址不會變。
